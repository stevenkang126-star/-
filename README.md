# 신우회 출석부

교회 신우회 출석 관리를 위한 설치형 웹앱(PWA)입니다. 서버나 회원가입 없이 브라우저에서 바로 쓰고, 안드로이드 크롬에서는 앱처럼 설치해 쓸 수 있습니다.

## 쓰는 방법

1. 폰 크롬에서 이 페이지를 엽니다: <https://stevenkang126-star.github.io/-/>
2. 크롬 오른쪽 위 ⋮ 메뉴 → **앱 설치**(또는 **홈 화면에 추가**)를 누르면 주소창 없는 앱으로 열립니다.
3. 처음에는 명단이 비어 있습니다. **명단** 탭에서 한 명씩 추가하거나, **일괄 등록**(CSV/엑셀 붙여넣기)으로 한 번에 넣으세요.
4. 출석은 **출석** 탭에서 날짜·모임을 고르고 출석/결석/사유를 누르면 됩니다.
5. **기도제목** 탭에서 신우별 기도제목을 적고, 응답을 받으면 ‘응답 체크’로 감사 표시를 합니다.

## 화면

| 탭 | 하는 일 |
| --- | --- |
| 출석 체크 | 날짜·모임별 출석/결석/사유 체크, 일괄 출석, 인쇄, 그날 CSV |
| 기도제목 | 신우별 기도제목 작성·수정·삭제, 응답됨(감사) 표시, 신우·상태 필터와 검색, CSV |
| 신우 명단 | 신우 등록·수정·삭제, 입대일·전역일·생일 표시, 일괄 등록, 명단 CSV |
| 통계·기록 | 개인별 출석률, 연속 결석, 날짜별 기록, CSV 내보내기 |
| 저장·백업 | 저장 상태 확인, JSON 백업/복원, 데이터 비우기 |

## 자료 보관

- 입력한 명단·출석 기록·기도제목은 **그 기기 브라우저의 저장소(localStorage)에만** 저장됩니다. 서버로 전송되지 않습니다.
- 그래서 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다. **백업** 탭에서 JSON 내보내기로 주기적으로 백업하세요. 백업 파일에는 기도제목도 함께 들어가고, 예전 버전에서 만든 백업 파일도 그대로 불러올 수 있습니다.
- 오프라인에서도 열립니다(서비스 워커가 파일을 캐시).

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (단일 파일, 외부 라이브러리 없음) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 배포 · 업데이트

- 실제 서비스 주소는 GitHub Pages의 `gh-pages` 브랜치에서 나옵니다: <https://stevenkang126-star.github.io/-/>
- `main`과 `gh-pages` 두 브랜치의 내용을 같게 유지합니다. `index.html`을 고친 뒤 두 브랜치에 모두 올리세요.
- 앱을 한 번 설치한 기기는 서비스 워커 캐시를 씁니다. 새 버전을 올릴 때는 `sw.js`의 `CACHE_NAME`(예: `sinyuhoe-attendance-v2`)을 올려야 홈 화면 앱에도 반영됩니다.
- 폰에서는 앱을 완전히 닫았다 다시 열면 새 버전이 적용됩니다.
