# 신우회 출석부

교회 신우회 출석 관리를 위한 설치형 웹앱(PWA)입니다. 서버나 회원가입 없이 브라우저에서 바로 쓰고, 안드로이드 크롬에서는 앱처럼 설치해 쓸 수 있습니다.

## 쓰는 방법

1. 폰 크롬에서 이 페이지를 엽니다: <https://stevenkang126-star.github.io/sinyuhoe-attendance/>
2. 크롬 오른쪽 위 ⋮ 메뉴 → **앱 설치**(또는 **홈 화면에 추가**)를 누르면 주소창 없는 앱으로 열립니다.
3. 처음에는 명단이 비어 있습니다. **명단** 탭에서 한 명씩 추가하거나, **CSV/엑셀 붙여넣기**로 한 번에 넣으세요.
4. 출석은 **출석** 탭에서 날짜·예배를 고르고 참석/결석/사유를 누르면 됩니다.

## 자료 보관

- 입력한 명단과 출석 기록은 **그 기기 브라우저의 저장소(localStorage)에만** 저장됩니다. 서버로 전송되지 않습니다.
- 그래서 기기를 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다. **백업** 탭에서 JSON 내보내기로 주기적으로 백업하세요.
- 오프라인에서도 열립니다(서비스 워커가 파일을 캐시).

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (단일 파일, 외부 라이브러리 없음) |
| `manifest.webmanifest` | 앱 이름·아이콘·전체화면 설정 |
| `sw.js` | 오프라인 실행용 서비스 워커 |
| `icon-192.png`, `icon-512.png` | 앱 아이콘 |

## 업데이트

`main` 브랜치에 파일을 올리면 1~2분 뒤 반영됩니다. 폰에서는 앱을 완전히 닫았다 다시 열면 새 버전이 적용됩니다.
